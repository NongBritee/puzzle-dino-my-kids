# 🦖 ไดโนจิ๊กซอว์ (Dino Puzzle for Kids)

เกมจิ๊กซอว์ 2D สำหรับเด็กอนุบาล 2-3 ขวบ เล่นบนเว็บ ไม่ต้องติดตั้งหรือ build

- ไดโนเสาร์ตัวใหญ่ 15 ชนิด (10 แบบฉากกว้าง + 5 แบบการ์ตูนตัวละคร) แต่ละตัวมีฉากแฟนตาซีไม่ซ้ำกัน (SVG วาดด้วยโค้ด)
- 1 ภาพ = 9 ชิ้น (3×3) หรือโหมดง่าย 4 ชิ้น (2×2)
- ลากวาง (นิ้ว/เมาส์), ถ้าวางใกล้ถูกที่จะดูดเข้าที่ ผิดชิ้นจะเด้งกลับ, แตะชิ้นเพื่อดูตำแหน่ง, ปุ่ม 💡 ใบ้
- เสียงสังเคราะห์ด้วย Web Audio + อ่านชื่อด้วย speechSynthesis (th-TH)
- เก็บดาว ⭐ ใน localStorage

## เล่น
เปิด `index.html` ในเบราว์เซอร์ หรือ `python3 -m http.server` แล้วเข้า http://localhost:8000
(ใช้ GitHub Pages โฮสต์ได้เลย เพราะเป็นไฟล์ static)

## โครงสร้าง
- `js/art.js` ภาพไดโนเสาร์ 10 แบบ (เพิ่ม/แก้ได้ที่ `window.DINOS`)
- `js/game.js` ตรรกะเกม, `css/style.css` หน้าตา
- เปลี่ยนจำนวนชิ้น: ปุ่มระดับใน `index.html` (`data-n`, ชิ้น = n×n)
